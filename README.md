# Iskra — UX-аудит

[Открыть публичный отчёт](https://davidishe.github.io/iskra-ux-audit/)
· [Скачать HTML](https://davidishe.github.io/iskra-ux-audit/iskra-ux-audit-2026-10-30.html)

Срез от 30 октября 2026 года: iOS 1.0 (16) и административный веб-интерфейс.
14 замечаний: 4 P1, 6 P2, 4 P3. Для каждого — проблема, сценарий, влияние,
предложение, критерий готовности и скриншот. Реальные платежи не выполнялись.

Отчёт адаптирован для телефона и компьютера. В HTML встроены уменьшенные
изображения; после скачивания текст и снимки доступны без сети.
Оригиналы PNG находятся в `evidence/`. Увеличение снимков и фильтры работают
в современном браузере. Для экспорта в PDF есть кнопка печати.

Это отдельный публичный репозиторий отчёта. Исходников приложения,
серверной конфигурации, ключей и рабочих пользовательских данных здесь нет.
На иллюстрациях — искусственные аккаунты и демо-анкеты из тестового стенда.
Цены на разных тестовых стендах могут различаться; они не являются офертой.

Аудит — экспертная оценка с наблюдениями и целевыми проверками. Исследование
с реальными пользователями, все роли и ошибки сети, полный сценарий регистрации,
полная проверка доступности и реальные списания в этот срез не входят.
Продуктовые исправления по замечаниям аудита не выполнялись.

`index.html` и `iskra-ux-audit-2026-10-30.html` содержат одинаковый отчёт;
`findings.json` — структурированные замечания. История — в [Changelog.md](Changelog.md).
